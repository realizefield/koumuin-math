KQU11　平行移動・対称移動の応用

公務員初級 ── x・y両方向の平行移動 ＋ x軸・y軸・原点への対称移動
① 解説
② 演習
③ 確認

1．平行移動の復習　── y＝f(x) を移動する

y＝f(x) を x 軸方向に a、y 軸方向に b 平行移動したグラフは

✅ 平行移動の公式

y－b ＝ f(x－a)

x を (x－a) に、y を (y－b) に置き換えるだけ！
x 方向に＋a 移動 → (x－a)　符号が逆になる

📌 例題①　y＝x²＋4x－1 を x 軸方向に 2、y 軸方向に 3 だけ平行移動した式を求めよ
x を (x－2)、y を (y－3) に置き換える
y－3 ＝ (x－2)²＋4(x－2)－1
y－3 ＝ x²－4x＋4＋4x－8－1
y－3 ＝ x²－5
y ＝ x²－2
📌 例題②　y＝2x²－8x＋5 は y＝2x²＋4x＋7 にどのように平行移動すればよいか
【スタート】y＝2x²－8x＋5 を平方完成
　y ＝ 2(x－2)²－3　→ 頂点 (2, －3)

【ゴール】y＝2x²＋4x＋7 を平方完成
　y ＝ 2(x＋1)²＋5　→ 頂点 (－1, 5)

移動量 ＝ ゴール－スタート
　x 軸方向：－1－2 ＝ －3
　y 軸方向：5－(－3) ＝ 8
💡 逆問題のコツ
両方の式を平方完成して頂点を求める → ゴール－スタートで移動量がわかる

2．対称移動とは？

グラフを「鏡に映したように」反転させることです。

📖 点 A(1, 2) の対称移動
x 軸対称 → B(1, －2) ← y の符号が逆
y 軸対称 → C(－1, 2) ← x の符号が逆
原点対称 → D(－1, －2) ← 両方の符号が逆

🔵 x 軸対称

y を －y に置換
－y ＝ f(x)
グラフが上下に反転

🟢 y 軸対称

x を －x に置換
y ＝ f(－x)
グラフが左右に反転

🟣 原点対称

x→－x、y→－y
－y ＝ f(－x)
上下＋左右に反転

✅ 対称移動のまとめ（重要！）

対称移動の種類置き換え方式の形
x 軸に関して対称y を －y に－y ＝ f(x)
y 軸に関して対称x を －x にy ＝ f(－x)
原点に関して対称x→－x、y→－y－y ＝ f(－x)

3．対称移動の例題

📌 例題③　y＝(x＋1)²＋1 を（1）x 軸（2）y 軸（3）原点に対称移動した式を求めよ
1
🔵 x 軸に関して対称　── y を －y に置き換える
－y ＝ (x＋1)²＋1
y ＝ －(x＋1)²－1 （上下反転、頂点は (－1, －1) に）
2
🟢 y 軸に関して対称　── x を －x に置き換える
y ＝ (－x＋1)²＋1 ＝ (x－1)²＋1
y ＝ (x－1)²＋1 （左右反転、頂点は (1, 1) に）
3
🟣 原点に関して対称　── x→－x、y→－y
－y ＝ (－x＋1)²＋1
y ＝ －(x－1)²－1
y ＝ －(x－1)²－1 （頂点は (1, －1) に）
💡 頂点の変化でチェックしよう
元の頂点 (－1, 1) が対称移動でどう変わるか：
x 軸対称 → (－1, －1) ← y が逆
y 軸対称 → (1, 1) ← x が逆
原点対称 → (1, －1) ← 両方逆

4．一般形 y＝ax²＋bx＋c での対称移動

📌 例題④　y＝－2x²＋3x－1 を次の移動した式を求めよ
① x 軸対称（y を－y に）
　－y ＝ －2x²＋3x－1
　y ＝ 2x²－3x＋1

② y 軸対称（x を－x に）
　y ＝ －2(－x)²＋3(－x)－1 ＝ －2x²－3x－1
　y ＝ －2x²－3x－1

③ 原点対称（x→－x、y→－y）
　－y ＝ －2(－x)²＋3(－x)－1 ＝ －2x²－3x－1
　y ＝ 2x²＋3x＋1
⚠ x 軸対称のポイント
y を－y に置き換えると 全係数の符号が逆になる だけです。
a が正なら負に、負なら正になります。（上下が反転）

5．平行移動と対称移動の組み合わせ

公務員試験では「平行移動してから対称移動」という複合問題が出ます。

💡 逆向きに解くのがコツ！
「移動してから対称」の問題は、最後の状態から逆の操作をたどると元の式が求まります。
対称の逆 → 同じ対称をもう一度行う
平行移動の逆 → 符号を逆にして平行移動
📌 例題⑤　y＝ax²＋bx＋c を x 軸方向に 5、y 軸方向に－2 平行移動し、さらに x 軸対称移動したら y＝－3x²＋12x－15 になった。a, b, c を求めよ
1
結果の式を x 軸対称に戻す（x 軸対称の逆＝再び x 軸対称）
y＝－3x²＋12x－15 の y を－y に置き換える
－y＝－3x²＋12x－15
y＝3x²－12x＋15
2
平行移動を逆にたどる（x方向に－5、y方向に＋2）
x を (x＋5)、y を (y－2) に置き換える
y－2＝3(x＋5)²－12(x＋5)＋15
y－2＝3x²＋30x＋75－12x－60＋15
y＝3x²＋18x＋32
a＝3、b＝18、c＝32

6．練習問題

① y＝x²－5x＋2 を x 軸・y 軸・原点それぞれに対称移動した式を求めよ
▶ 解答を見る
x 軸対称：y を－y に → y＝－x²＋5x－2
y 軸対称：x を－x に → y＝x²＋5x＋2
原点対称：両方置換 → y＝－x²－5x－2
② y＝x²＋2x－3 を x 軸方向に－3、y 軸方向に 3 平行移動し、さらに原点対称移動した式を求めよ　（公務員・看護学校頻出！）
▶ 解答を見る
① 平行移動：x を(x＋3)、y を(y－3) に置き換える
　y－3 ＝ (x＋3)²＋2(x＋3)－3
　y ＝ x²＋6x＋9＋2x＋6－3＋3 ＝ x²＋8x＋15

② 原点対称：x を－x、y を－y に置き換える
　－y ＝ (－x)²＋8(－x)＋15 ＝ x²－8x＋15
　y ＝ －x²＋8x－15
③ y＝2x²－4x＋4 を原点に関して対称移動した式を求めよ
▶ 解答を見る
x を－x、y を－y に置き換える
－y ＝ 2(－x)²－4(－x)＋4 ＝ 2x²＋4x＋4
y ＝ －2x²－4x－4

📋 まとめ

移動の種類操作符号の変化
x 軸方向に a 平行移動x → (x－a)方向と逆の符号
y 軸方向に b 平行移動y → (y－b)方向と逆の符号
x 軸対称y → －y全係数が逆
y 軸対称x → －x奇数次の符号が逆
原点対称x → －x、y → －yx軸＋y軸の両方
