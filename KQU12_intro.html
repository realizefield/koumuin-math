KQU12　判別式の応用

公務員初級 ── 常に正・常に負になる条件を判別式で求める
① 解説
② 演習
③ 確認

1．判別式 D とは？（復習）

二次方程式 の解の個数は 判別式 D で判断できます。

✅ 判別式の公式

b²－4ac の値の 符号だけ を見ればよい！

D > 0

x 軸と
2点で交わる
（異なる2つの実数解）

D ＝ 0

x 軸に
接する
（重解・共有点1個）

D < 0

x 軸と
交わらない
（実数解なし）
💡 今回のポイント
D < 0 ＝ x 軸と交わらない → グラフ全体が x 軸の上か下にある
これを使って「常に正」「常に負」になる条件を求めます！

2．常に正（y > 0）になる条件

y＝ax²＋bx＋c がすべての x に対して y > 0 になるとは？

📖 グラフのイメージ
グラフ全体が x 軸より 上 にある状態です。
そのためには「上に開く（a > 0）」かつ「x 軸と交わらない（D < 0）」が必要です。

✅ 常に正の条件

a > 0　かつ　D < 0

（上に開く放物線が x 軸より常に上にある）

📌 例題①　y＝x²－4x＋k がすべての x で y > 0 になる k の範囲を求めよ
1
a の符号を確認する

a＝1 > 0 → 上に開く ✅
「常に正」には D < 0 の条件が必要

2
判別式 D を計算する
3
D < 0 を解く
⚠ 両辺を −4（負）で割ると不等号が逆になる！

✅ 答え

k > 4

3．常に負（y < 0）になる条件

y＝ax²＋bx＋c がすべての x に対して y < 0 になる条件は？

✅ 常に負の条件

a < 0　かつ　D < 0

（下に開く放物線が x 軸より常に下にある）

⚠ 符号のトラップ！
a < 0 のとき D を計算すると 「－4ac」の符号が変わる ことに注意！
例：a＝−1 のとき −4×(−1)×k ＝ ＋4k　（プラスになる！）
📌 例題②　y＝−x²＋2x＋k がすべての x で y < 0 になる k の範囲を求めよ
1
a の符号を確認する

a＝−1 < 0 → 下に開く ✅
「常に負」には D < 0 の条件が必要

2
判別式 D を計算する
⚠ −4×(−1)×k ＝ ＋4k　マイナス×マイナス＝プラス！
3
D < 0 を解く

✅ 答え

k < −1

4．応用　── k が b・c 両方に含まれる場合

📌 例題③　y＝x²＋kx＋k がすべての x で y > 0 になる k の範囲を求めよ
1
a＝1 > 0 → D < 0 が条件
2
D を計算する（b＝k、c＝k）
3
D < 0 を因数分解して解く
k(k−4) < 0 → 「内側ルール」で 0 < k < 4

✅ 答え

0 < k < 4

💡 内側ルール（2次不等式の解）
(k−α)(k−β) < 0　（α < β）のとき → α < k < β（内側）
(k−α)(k−β) > 0　（α < β）のとき → k < α または k > β（外側）

📋 まとめ

条件a の符号D の条件意味
常に正（y > 0）a > 0D < 0x 軸より常に上
x 軸と接する任意D ＝ 0ちょうど1点で接触
常に負（y < 0）a < 0D < 0x 軸より常に下
⚠ 手順の確認
① まず a の符号を見る → 常に正なら a > 0、常に負なら a < 0
② D ＝ b²－4ac を計算する（符号ミスに注意！）
③ D < 0 を解いて k の範囲を求める
